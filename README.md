# Sistema de Gestión de Ventas

Aplicación CRUD desarrollada con **Streamlit** y **SQLite**.

## Funcionalidades
- Gestión de Clientes
- Gestión de Proveedores
- Gestión de Stock
- Gestión de Ventas
- Gestión de Detalle de Ventas
